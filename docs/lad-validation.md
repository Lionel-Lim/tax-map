# Phase 1 LAD input validation

The five LAD results use their independently published ONS authority median and VOA authority band counts. They do not average MSOA prices or aggregate typical-home tax results. All monetary source values are converted to integer pence; weighting retains an exact rational number of pence.

## Stock schema and geography

The source is the pinned `voa-stock-all` archive and member `CTSOP1.1/CTSOP1_1_2025_03_31.csv`. The importer requires the full column sequence `geography,ba_code,ecode,area_name,band_a,band_b,band_c,band_d,band_e,band_f,band_g,band_h,band_i,all_properties`. A LAD row must have `geography=LAUA` and a valid LAD GSS code in `ecode`. MSOA rows use `geography=MSOA`; LSOA, regional and county totals are excluded. `ba_code` is retained for provenance, never used as a GSS key. English band I must be `..` and is excluded from weighting.

The archived CSV notes explicitly define `LAUA` as local/unitary authorities/London boroughs. Their billing-authority notes describe Cumberland's 2023 formation. The live [VOA background guidance, sections 3.3–3.4](https://www.gov.uk/government/statistics/council-tax-stock-of-properties-2025/background-information#assigning-geographies), checked 26 September 2026, identifies CTSOP1.1 as postcode assigned using NSPL February 2025. CTSOP1.0 uses billing-authority codes and is not an interchangeable reconciliation source. The source's unmatched row is preserved in the validation report, rather than allocated to an area.

The stock snapshot is 31 March 2025. The independently published LAD price sheet is ONS `2a`, header row 3, code C and September 2025 price DT. The map boundary is LAD May 2025 BSC V2, verified against the pinned feature-layer metadata. The current charge sheet joins by `Data_Billing!B` and uses the full charge in AL.

There are 296 English LAUA stock rows and 296 current English LAD boundary codes. Two old stock codes are excluded from current LAD statistics: Barnsley `E08000016` → `E08000038`, Sheffield `E08000019` → `E08000039`. Their totals must not be relabelled onto changed boundaries. These authorities are outside this sample. The importer fails for additional unexplained vintage mismatches. Leicester, Wandsworth, Burnley, Cumberland and North Yorkshire have direct published stock rows and exact current price, boundary and charge codes. Their sample MSOA inventory also agrees with the official current parent lookup. Postcode evidence provides an additional check for cross-authority MSOAs; affected MSOA estimates are withheld while the independently published LAD inputs remain usable.

## Reconciliation and marker handling

For each LAD, the sum of its eight rounded bands must be within 45 dwellings of its separately rounded `all_properties`. The denominator is the sum of bands. Zero remains zero; `-`, `[c]`, blank and unknown symbols retain their raw values and make an affected result unavailable. A missing source row still produces the selected area's explicit unavailable row. Duplicate GSS keys, unexpected source codes, conflicting official parents and excessive reconciliation differences fail the build.

The following secondary check sums the published MSOA `all_properties` cells from the same CTSOP1.1 table. All sample MSOAs retain the same observed stock parent as their official parent. Its tolerance is `5 × (MSOA count + 1)` dwellings. This check uses independently rounded totals, including totals of MSOAs whose individual band cells are unavailable. It does not fill those bands or prove every MSOA nests inside a billing authority.

## Independently checked Leicester LAD example

The committed [fixture](../data/fixtures/phase1-lad-worked-example.json) contains separately transcribed source inputs and expected arithmetic. It is not generated by the production importer. The release build checks the inputs and exact baseline against it.

| Source | Location | Input |
| --- | --- | --- |
| ONS LAD price | `2a!DT67`, code `E06000016` | £244,922 |
| VOA LAD stock | CSV row 11,832, `geography=LAUA` | A 86,920; B 28,280; C 16,980; D 7,340; E 3,580; F 1,590; G 610; H 60 |
| VOA published total | Same row | 145,350 |
| Full Band D charge | `Data_Billing!AL149` | £2,528.75 |
| Charge components | Z, AH, AI, AJ, AK on row 149 | £2,121.87 + £0 + £315.23 + £91.65 + £0 |

The eight band counts sum to 145,360, a 10-dwelling reconciliation difference. The independently weighted sum is `6×86,920 + 7×28,280 + 8×16,980 + 9×7,340 + 11×3,580 + 13×1,590 + 15×610 + 18×60 = 991,660`.

```text
Council Tax baseline = 252,875 pence × 991,660 / (9 × 145,360)
                     = 12,538,301,125 / 65,412 pence
                     = £1,916.8197158… → £1,916.82
Illustrative scenario = £244,922 × 0.0048 = £1,175.6256 → £1,175.63
Annual difference     = −£741.1941158… → −£741.19
Monthly equivalent    = −£61.7661763… → −£61.77
```

The fixture also pins the underlying source identifiers, raw band strings and exact result fractions. Unit tests exercise missing inputs, raw markers, zero counts, duplicate keys, schema changes, geography quarantine and incorrect reconciliation independently of the real-source integration test. The result remains a gross area estimate using an authority-average charge, subject to the source-period and population limitations in the [methodology](methodology.md).
