# Reproduce the Phase 0 audit

This script verifies source hashes, reads the relevant data fields, checks geographic inventories and charge joins, and rebuilds the sample selection and worked-example fixtures. It makes no network requests and does not evaluate workbook formulas or external links.

Use Python 3.11 or newer with `openpyxl==3.1.5`, as listed in `requirements.txt`:

```sh
python3 scripts/phase0/audit.py
```

The original source files are cached under `data/raw/phase0/`, excluded from Git. On another checkout, download every source from `data/source-manifest.json` to its `localPath` before running the audit. The script checks the exact SHA-256 hashes before parsing; a changed source needs review and an explicit repin, not an automatic update. Some ArcGIS metadata responses can change without the underlying statistics changing; review those separately.

The checked environment used the Codex bundled Python runtime and openpyxl 3.1.5. The runtime is only a reading dependency; the future application's dependency setup is separate.

Generated outputs:

- `data/fixtures/phase0-sample-areas.json`
- `data/fixtures/phase0-sample-boundaries.geojson`
- `data/fixtures/phase0-worked-examples.json`
- `docs/evidence/phase0-validation.json`

The script reads ONS sheet `1a` for MSOAs and `2a` for LADs, selecting the September 2025 column by its header. It reads cached values from the selected Council Tax ODS worksheet and converts monetary fields to pennies. The independently specified synthetic examples are not regenerated by the script.

This audit establishes a source contract and small fixtures. It does not build postcode shards, produce the application dataset, certify polygon topology or resolve the outstanding source limitations in `docs/phase0-findings.md`.
