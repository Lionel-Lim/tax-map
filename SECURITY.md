# Report a security issue

**Use GitHub's private [Report a vulnerability](https://github.com/Lionel-Lim/tax-map/security/advisories/new) form when it is available.** Include the affected page or file, impact and steps to reproduce the issue. Use dummy values instead of live credentials or personal data.

If private reporting is unavailable, open an issue titled **Private security contact requested** with no vulnerability details. Wait for a private contact method before sharing the report.

Security fixes target the latest code on `main`. Older versions are not maintained separately. For calculation errors or data corrections without a security impact, use a normal issue.
